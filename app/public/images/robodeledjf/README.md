# Fotos da landing page

Salve aqui as fotos do Instagram [@robodeledjf](https://www.instagram.com/robodeledjf/)
com exatamente estes nomes. A galeria da página inicial procura por eles:

| Arquivo             | Legenda na página                |
| ------------------- | -------------------------------- |
| `robo-1.jpg`        | Robô de LED na pista             |
| `robo-2.jpg`        | Entrada dos noivos               |
| `balanco-1.jpg`     | Balanço de LED personalizado     |
| `festa-1.jpg`       | Aniversário infantil             |
| `festa-2.jpg`       | Nome do aniversariante no painel |
| `tequileiro-1.jpg`  | Mega tequileiro                  |

Recomendações:

- proporção vertical (4:5), por exemplo 1080x1350 px;
- até ~400 KB por foto, para a página carregar rápido;
- `.jpg` (se preferir `.webp`, ajuste os nomes em `src/pages/Landing.jsx`).

Enquanto um arquivo não existir, a página mostra um bloco decorativo no lugar da foto —
nada quebra. Para mudar legendas ou adicionar mais fotos, edite a lista `GALLERY`
em `app/src/pages/Landing.jsx`.
